# 凋亡生信图谱

细胞凋亡机制与生物信息学分析流程的交互式网站。

**在线访问：** https://fuzzylogic112.github.io/apoptosis-atlas/

## 内容

| 模块 | 说明 |
|---|---|
| 流式模拟 | Annexin V / PI 双染散点图，拖动药物处理时间观察四象限比例变化 |
| 凋亡通路 | 外源性（死亡受体）、内源性（线粒体）与执行阶段；点击基因查看功能与上下游，5 个情景高亮信号路径，可叠加示例表达谱 |
| 分析流程 | 数据获取 → 预处理 → 差异分析 → 凋亡基因集交集 → 富集 → PPI → 机器学习 → 临床与免疫 → 实验验证，每步附要点、常见问题和可复制的 R 代码 |
| 差异表达 | 阈值可调的火山图，自动统计上调、下调和凋亡相关差异基因（ARDEGs） |
| 富集分析 | GO / KEGG 气泡图；GSEA 的 ES、NES 与 leading edge 在浏览器中实时计算 |
| PPI 网络 | 可拖动的互作网络，Degree / Betweenness / Closeness 三种中心性的 Top 10 及交集 |
| 基因库 | 42 个凋亡相关基因，按类别、作用和关键词筛选 |

## 数据说明

火山图、富集结果、GSEA、PPI 边和流式图中的数值均为**模拟数据**，用于演示分析思路，不代表任何真实数据集。通路机制、基因功能、GO / KEGG 条目名称与 R 代码基于公认的凋亡机制和常用 Bioconductor 工具。

## 技术

- 单个 `index.html`，无需构建，直接由 GitHub Pages 托管
- 图表使用 [D3.js](https://d3js.org) v7.9.0（`assets/d3.min.js`，ISC 许可），已随仓库分发，不依赖外部 CDN
- 自动跟随系统的浅色 / 深色模式，适配手机屏幕

本地预览：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
